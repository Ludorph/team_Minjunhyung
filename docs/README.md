## 규칙

- 새 주차 산출물은 해당 분류 폴더에 `문서명_v버전.docx`로 추가하고, 주간 보고서와 AI 활용 로그는 `07_주간보고/<n>주차/`에 둔다.
- 이전 프로젝트명은 파일명과 본문에 쓰지 않는다 (팀 코딩 규칙 1장).
- 수강생 명단 등 개인정보가 들어간 자료는 저장소에 올리지 않는다.
